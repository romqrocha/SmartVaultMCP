### `pwd`

**Print Working Directory** – Shows the current directory path you're in.

---

###  `man`

**Manual Pages** – Opens the manual/help documentation for a command (e.g., `man ls`).

---

### `clear`

**Clear Screen** – Clears the terminal display.

---

### `ls`

**List** – Lists files and directories in the current directory.

---

### `lsb_release`

**Linux Standard Base Release Info** – Displays OS version info. `-a` shows all details.

---

### `touch`

**Create Empty Files** – Creates one or more empty files, or updates timestamps.

---

### `tree`

**Directory Tree** – Recursively displays the directory structure in a tree format.

---

### `mkdir`

**Make Directory** – Creates one or more new directories.

---

### `cd`

**Change Directory** – Moves to a different directory.

---

### `cat`

**Concatenate & Display** – Displays the contents of files. Options like `-n` number the lines.

---

### `rm`

**Remove** – Deletes files or directories. Use `-r` for recursive deletion.

---

### `history`

**Command History** – Shows a list of previously run commands.

---

### `echo`

**Print Text to Terminal** – Displays a message or writes to a file using `>` or `>>`.

---

### `gcc`

**GNU Compiler Collection** – Compiles C/C++ source code into executables.

---

### `pstree`

**Process Tree** – Displays running processes in a hierarchical (tree) structure.

---

### `fg`

**Foreground** – Resumes a background job and brings it to the foreground.

---

### `jobs`

**List Jobs** – Shows background jobs started in the current terminal session.
