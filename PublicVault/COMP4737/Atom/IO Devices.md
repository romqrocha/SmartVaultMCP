- Generally consist of two parts; a [[#Controller]] and the [[#Hardware]]
# Controller
- A chip or a set of chips that physically control the [[#Hardware]]
- Usually complicated and detailed, so it presents a simpler interface for the [[Operating System|OS]]
	- Often receives commands from a [[Device Driver]] rather than the OS itself
- Often contain small, embedded computers to handle their work
# Hardware
- Usually have fairly simple interfaces
	- A SATA disk controller can handle any SATA disk
