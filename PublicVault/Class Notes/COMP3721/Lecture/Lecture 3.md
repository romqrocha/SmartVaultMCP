# Physical Layer
- All data sent across the physical layer is sent as electromagnetic signals across a transmission medium
- Data needs to be changed to signals for transmission
- Hardware controlled layer(modem)

# Signals
- Periodic
	- Cycle: 1 full pattern
	- Period: The amount of time it takes to complete one Cycle
	- A simple periodic analog signal(A sine wave) cannot be broken into simpler signals
- Period and frequency are inverse of each other
	- Period = 1/F
	- Freq = 1/P
# Analog Signals
- Continuous
- Examples:
	- Sound
	- Temperature
# Digital Signals
- Discrete states
	- Finite values(often 0 and 1)
- Example:
	- Bits

# Sine wave
- Simplest Analog Periodic wave
- Peak amplitude
	- Absolute value of highest intensity
	- measured in **volts**
- Frequency(Peroid)
	- Cycles per second (1/Seconds)
- Phase/Phase Shift
	- Position of the wave relative to time 0
	- Measured in degrees or radians
## Example:
- Voltage in Canada is Periodic(A/C)
	- Peak value of 120sqrt2 - equals about 120V
		- Frequency of 60hz
- Battery is constant, 1.5V for example
	- Periodic with a frequency on 0
