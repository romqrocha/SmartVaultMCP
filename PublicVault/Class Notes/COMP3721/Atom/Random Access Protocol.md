- AKA Contention Protocols
- No host is superior or another host, and none is assigned control over another
	- Each host can transmit when it desires, so long as it follows the procedure
- Two features:
	1. Random Access
		- No scheduled time for a station to transmit
	2. Contention Among Stations/Hosts
		- No rules for which station should send next
- When there is a collision, the frame is either destroyed or modified
- To avoid collisions, each station follows a procedure:
	- When to access the medium?
	- What to do if the medium is busy?
	- What to do if there is a collision?
	- How to determine the success or failure of the transmission?
