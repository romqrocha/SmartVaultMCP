- Each AS is operated by a single large organization
	- e.g. an [[ISP]], large tech company, university, government
- Each AS is given an Autonomous System Number by [[ICANN]]
	- a 16-bit unsigned int uniquely identifies an AS
- Each AS can run a [[Routing Protocols]] that meets its needs
- The Global Internet runs a **Global Protocol** to glue all the AS together
- Two common intradomain routing protocols: [[Routing Information Protocol|RIP]] and [[Open Shortest Path First|OSPF]].
- Only **inter**domain routing protocol is [[Boarder Gateway Protocol]]
