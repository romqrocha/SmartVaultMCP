Earliest [[Random Access Protocol]]
- Designed for radio/wireless [[LAN]]
- Each station sends a frame whenever it has a frame to send
- Relies on acknowledgements from the receiver
# Backoff Time($T_B$)
- When timeout for acknowledgement passes, wait a random amount of time
- The Random Time ($R$) waited depends on number of unsuccessful transmissions ($K$)
- After a maximum number of attempts($K_{max}$, the station gives up and tries again
# Max Propagation Time(Delay)($T_P$)
- Amount of time required to send a frame between the two mode widely separated station
- $T_P$ = distance / propagation speed
- Maximum round-trip delay is $2 * T_P$
- Time-out period is equal to $2 * T_P$
# Average Transmission Time($T_{fr}$)
- Average amount of time required to send out a frame
- $T_{fr}$ = frame size / transmission rate
# Vulnerable Time
- The length of time in which there is a possibility of a collision
- For ALOHA, $2 * T_{fr}$
# $G$
- The average number of frames generated by the system during one frame transmission time
# Throughput 
- $S = G * e^{-2G}$
- Maximum $S_{max} = 0.184$ when $G = 1/2$
