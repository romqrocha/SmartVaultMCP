# Interframe Space
- Collisions are avoided by deferring transmission even if the channel is found idle
# Contention Window
- After waiting an [[#Interframe Space|IFS]] time, if the channel is still idle, the station can send.
- Still needs to wait for a period of time called the **Contention Window**
# Network Allocation Vector
- A timer we use to ensure the network is free
