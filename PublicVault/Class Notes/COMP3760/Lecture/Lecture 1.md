# Algorithms
## #fc #definition Algorithms
- A sequence of unambiguous instructions for obtaining a required output for any legitimate input in a finite amount of time

## Design techniques
- Brute Force
- Divide and Conquer
- Decrease and Conquer
- Transform and Conquer
- Space and Time Tradeoffs
- Greedy approach
- Dynamic
- Iterative improvement
- Backtracking
- Branch and Bound

## Problem types
- Sorting
- Searching
- String processing
- Graph problems
- Combinatorial
- Numerical
- Optimization

- There is always more than one algorithm to solve the same problem
- We care about:
	- Is it correct
	- Is it time-efficient
	- is it space-efficient
