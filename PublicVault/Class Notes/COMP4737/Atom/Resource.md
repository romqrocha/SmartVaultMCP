>[!note]- A resource is anything that must be acquired, used, and released over the course of a program
>Can be hardware(A gpu, a disk drive) or data(A record in a database, a file)
- To use a resource, you must
1) Request
2) Use
3) Release
- This is done via a [[Semaphore]] for each resource
- See [[Part_9_Deadlock.pdf#page=14&selection=6,0,8,11|Part_9_Deadlock, page 14]] for an example in code
