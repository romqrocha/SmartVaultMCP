# Null Pointer Exception

- Method made a call to an object that is undefined

# Array index out of bounds exception

- tried to call a index in a list/array that was beyond the scope.
    - Was it negative?
        - Was it larger than the maximum index of the collection?

# Stack Overflow

- Something is causing an infinite loop
    - Are you calling a function infinite times?

  

- Top is the “Exception Name”
- Below that is the “Stack Trace”
- Inside the Stack Trace gives you the method that package.class and method that causes the error
    - also includes the line #
- Debugger requires access to the Source Code, and Symbol Information ( Language construction information for human-readable output)
