- Templates set up document formatting so they are consistent
- Corporations have a **corporate** template so all their documents have a similar look and feel as part of their branding.
	- Company Logo in the header
	- Name of the document in the header
	- Use the colors of your logo in the heading structure
# Comm 1116 Template and Style Guide
- Buttons and Page Names are proper nouns
	- its Home Page and Account Page, but Home and Account pages(since plural is generic)
- front-end development
- Header
	- Document name 
	- page number, top right
	- Logo optional
- Every task, except task 1, starts on a new page
- Table of Contents should be a level 1 heading, but should not appear in the table
	- Should have tab leaders(...) between the title and the number
- Hanging indent for numbers
- Everything should be within the margins
- If a graphic doesn't spam the whole text, center it or put it in the margin
- Capitalize correctly
