# Letter of Transmittal
- 5 things that MUST be conveyed
	1. Authorization: Who decided to write it
	2. Purpose: Why did we write it
	3. Main conclusion: "We think you should adopt X because Y"
	4. Acknowledgements of help
	5. Comments that are useful, but do not belong
	6. Friendly close
- Addressed to 1 person
- Created as a separate document

# Title page
- required
	1. Descriptive title for the report
	2. Name and title of primary reader/organization
	3. Name and title of the authors or authoring organization
	4. Date of publication
# Table of contents
- Use Tab Leaders
# List of Tables and Figures
- Same thing as TOC but for graphic elements
- Usually immediately after TOC, on a separate page.
	- Unless they can be completed on the same page as the heading
# Summary
- Every reader who reads it should be able to understand it
- Adjust your style so its suitable for the widest possible audience
- Provides a synopsis.
- About 1/10th of the length of the report
	- Excluding the conclusions and recommendations
	- To a max of 1 page
	- Focus on summarizing Introduction, conclusions, and recommendations
- Placed on its own page.
- Immediately before introduction
- Order
	- Purpose
	- Problem/current situation from Intro
	- Solution
	- Implementation
		- Can include cost if its low
	- Benefits/Recommendations
# Introduction
- Current situation
	- Problem/need
	- Be specific
- Proposed Solution
	- Be brief
- Benefits
	- How the proposal will solve the problem
- Do **not** include findings in the introduction
- Indicate how the rest of the report is organized
# Conclusions and Recommendations
- Convenient end-summary of the most important info from the report
- Divides indisputable facts(Conclusions) from your professional opinion(Recommendations)
- Recommendations will have been implied or explicitly stated throughout the Discussion
- Recommendations brings those together in one convenient location
# Appendices
- For detailed, complex, or supplementary information
- Proofs for claims in the body
- Make sure you refer to the appendices in the body

# Pagination
- The orientation section in lower case Roman Numerals
	- Table of Content
	- List of Tables
	- List of Figures
- Do not paginate the Title page or appendices

# Grading
- All sections contain the right information
- Clear, concise, accurate, proper tone
- Format, Cover page, TOC, LTF, Headers, etc.
