- Information should be easy to find, since users will be going back and forth
- Step number should be hanging in the margin
	- Notes do not hang in the margin
- Perform the software task yourself
	- You'll understand the steps required
	- You'll check your memory
	- Use verbs in the imperative mood
- Give instructions, not directions
	- If you use an arrow or a highlight, you don't need to specify where on the screen the item is
