# What is Data

- Information is a statement based on data
- Data by itself has no meaning
- Generating information is easy, generating good data takes time
- A database contains
    - **Entities (tables)**
    - Entity Attributes(Table Columns)
    - There is always a relationship between tables
- In a table
    - a row is called a **record**
    - columns can also be called **fields**

  

  

- Select * FROM [database Name].[schema].[table]
- Key = ONE
- 8 = MANY

  

- Select * from Table A JOIN Table B ON A.Column = B.Column
