# DDL

Data Definition/Description Language

- Creates and modified database objects such databases, tables, indexes, users
- Defines database schemas and data structures
- Uses statements like CREATE, ALTER, DROP

  

- CREATE
    - used to create new database objects (Tables, Views, Stored procedures, Triggers)
- ALTER
    - used to modify the existing structure
- RENAME
    - used to rename an existing database object
- DROP
    - Used to delete existing database objects
- TRUNCATE
    - To remove existing data in a table

# DML

Data Manipulation Language

- Manipulates persistent database objects
- Uses statements like SELECT, INSERT, UPDATE, DELETE

  

- INSERT
    - To add new records to an object
- UPDATE
    - To modify existing data
- DELETE
    - To remove existing data
