This problem is in the "easy" category in Leetcode.  It involves merging two 2 dimensional arrays.

One possible solution involves the use of a map.

Another solution would be to use a counting sort algorithm.  This second solution works because the largest value can only be 1000.  In fact this solution is faster than the solution using a map.

Try coming up with a solution(s) on your own first.
