# Microservices
## Benefits
- Loose coupling of teams
	- each team has their own development/test/deploy/support cycle
	- "End-to-End ownership"
	- Separation of concerns
## Costs
- Fundamentally an org change
	- You need to rebuild the teams
## Requirements
- IPC is crucial
	- Define an interface/contract early
- Telemetry
	- You need to be able to quickly check system help
