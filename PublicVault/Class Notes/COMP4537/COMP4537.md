# Get vs Post
- Get **request** has a limited size
- Post **request** can be any size
- Response can be any size
# Promises
- 3 states:
	- Pending
	- Resolved(Fulfilled)
	- Rejected
	- Both Resolved and Rejected are considered "Settled"
- You can pass a function into a Promise that handles 2 arguments; the first being what happens on Resolve, and the 2nd being what happens on Reject
`let promise = new Promise(executor(resolve, reject)`
- You'll commonly see this done with anonymous functions
`let promise = new Promise((resolve, reject) => {...})`
- the resolve and reject arguments are callbacks
- They are **mutually exclusive** and always **async**
```js
let promise = new Promise((resolve, reject) => {
	if(/*some logic to check result*/)
	{
		resolve("Resolved!");
	}
	else
	{
		reject("Rejected);
	}
})
```
- You can chain functionality off the resolution of a promise using `.then(res, rej)`
```js
myPromise
  .then(handleFulfilledA, handleRejectedA)
  .then(handleFulfilledB, handleRejectedB)
  .then(handleFulfilledC, handleRejectedC);
```
- Each resolve and reject are handled independently; the first then may receive a resolve and raise a reject
