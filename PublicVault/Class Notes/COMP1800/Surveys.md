- Think about the answer would do for you
- There should be a logical flow to the questions
- Questions should be easy/defined
    - “Do you like to relax?”: Peoples definition of relaxed and relaxing is different
- Avoid double negatives
- Avoid questions with 2 concepts at the same time:
    - Rate X and Y; should be 2 questions
- Avoid 1-5 for rating
- Should be equal position and negative options
- Use open ended questions to get organic feedback
    - Hard to extract data, dont use too many
- Avoid conversational tone(?)
