- Use a “Progressive Enhancement” design
- Google uses the mobile version of websites for indexing

# What does Mobile-first mean?

- Minimal space available
    - What do users actually need to see?
- Try to use the devices hardware
- Optimize
    - Don’t make multiple screens load for 1 task
    - Reduce scrolling left/right

# Colors

- 60/30/10
- Only 1 primary color, max 3 colors
    - If needed, add a natural 4th color, like white

## Fonts

- Serifs
    - Traditional
- Sans Serif
    - Modern
- Rule of thumb - double/halve weights of adjacent lines
- Power-horse fonts: Robot, Open Sans, Arial
