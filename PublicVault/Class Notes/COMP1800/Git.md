Git

- git clone - replicate remote repo to **local** computer
- git init - turn a local dir into a **local** repo git add - to add (stage) file from your local
- git add - to add (stage) file from your **local** dir to the **stage/index.** Can also use git stage.
- git commit - move what’s in your **stage/index** to **local** repo
- git push - replicate **local** repo to **remote** repo

![[Git_Commit_process.png|Git_Commit_process.png]]

Stage: ‘save’ your local changes to a change list

Commit: save your local changes to your local repo

Push: Send your local repo, and any commits in it, to the remote repo

  

## .gitignore

a file that lists all the files listed within it, or within the patter. * for wildcard.

eg: *.class
