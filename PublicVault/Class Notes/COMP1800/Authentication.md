# Firebase

- Is a collection of services offered by google
- Allows us to get a backend without coding all the logic
- Gives us
    - Authentication
    - storage
    - non-sql database
    - analytics
- Also has a FirebaseUI Library that handles the login flow, password recover, etc.
- A firebase authenticated user is someone who has signed up through the firebase UI or the authentication UI

## Firestore

- the database portion of Firebase
- We can store the details we want about the user there
