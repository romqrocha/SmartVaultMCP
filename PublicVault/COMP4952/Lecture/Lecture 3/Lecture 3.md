# HCI
## Goals
- Design and implement systems that are
	- Functional
	- Effective
	- Enjoyable
	- Safe
	- Usable
# Usability
- Often the most neglected aspect of design.
>[!quote] If users can't properly use a web site, they will leave and never become customers
- A very important principle is to involve potential customers/users in the application design.
# Stages
1. Low-Fidelity Prototype
	- Assess the Needs of the user
	- Create user tasks and user profiles
	- design the first prototype(eg. Figma or Pen and Paper)
		- Apply heuristics of HCI
	- Usability study; Evaluate the usability of your prototype in a usability study
# Needs Assessment
>[!note] Systemic process for determining and addressing needs between current conditions and desired conditions (wants)
- Use
	- Surveys
	- Interviews
	- Stakeholder meetings
	- etc.
# Users
- Create a user profile
	- Demographics
	- Abilities
	- Personality differences
	- Preferences
	- Cultural/International diversity
	- Accessibility
# User and Task Analysis
- Look for Goals, Tasks, and Actions required
- User Observations, interviews, ask users to think about as they work, focus groups, and/or surveys
# Usability Studies
> [!note] Studies done with real users
- Studies should be carefully planned
- A usability report should always be the outcome
## Study Design
1. Identify participants
2. Create a questionnaire or survey
3. Methods:
	- Observe the users interacting with the prototype
	- Interview or survey users
4. Take notes of what you learned
5. Summarize
6. Make recommendations
7. Write the usability report
# Fitts' Law
- About modeling human movement
- says that the time required to move to a target area is a function of the *distance to the target* and the *size of the target*
- Used to model the art of pointing by physically or virtually pointing to an object via a pointer(finger or mouse)
